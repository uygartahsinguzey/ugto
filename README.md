# Berna v7.1

GitHub Pages üzerinde doğrudan çalışan, mobil uyumlu ve kurulabilir PWA sürümüdür.

## Çalıştırma

1. Tüm dosyaları GitHub deposunun kök dizinine yükle.
2. GitHub > Settings > Pages bölümünde kaynak olarak `Deploy from a branch` seç.
3. Branch olarak `main`, klasör olarak `/ (root)` seçip kaydet.
4. Birkaç dakika sonra GitHub Pages adresinden açılır.

## Özellikler

- Çalışan Pomodoro sayacı
- Başlat, duraklat ve süre ayarı
- Görev tamamlama ve yeni görev ekleme
- XP, seviye, coin ve Pomodoro ilerlemesi
- Oda mağazasından ürün satın alma
- Verilerin tarayıcıda kalıcı saklanması
- Mobil uyum ve PWA kurulumu
- GitHub Pages ile uyumlu göreli dosya yolları
