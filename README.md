# Berna V16 — App Store Clean

Berna, Miki ile birlikte odaklanmayı daha sıcak ve görünür hâle getiren statik bir üretkenlik uygulamasıdır.

## Bu sürümdeki ana değişiklikler

- Alt gezinme 9 sekmeden 5 sekmeye indirildi.
- Oda, gardırop ve koleksiyon Miki sekmesinde birleştirildi.
- Ayrı mağaza ve ayrı oda sekmeleri kaldırıldı.
- Sahte arkadaş ve oda ziyareti sistemi tamamen kaldırıldı.
- Coin, XP ve seviye ekonomisi kaldırıldı.
- Kostüm ve oda parçaları tamamlanan odak seanslarıyla açılır.
- Miki'nin sürekli azalan dört ihtiyacı kaldırıldı.
- Yerine azalmayan tek bir **Miki ile bağ** göstergesi getirildi.
- Başlangıçta yalnızca tek, tutarlı Cozy tema kullanılır.
- Alt sekmelerde emoji yerine özgün çizgi SVG ikonları kullanılır.
- Ayarlar sağ üstteki butona taşındı.

## GitHub Pages kurulumu

1. ZIP dosyasını çıkarın.
2. Klasörün içindeki tüm dosyaları GitHub deposunun kök dizinine yükleyin.
3. `Settings > Pages` bölümünde `Deploy from a branch`, `main`, `/(root)` seçin.
4. Eski sürüm önbellekte kalırsa sayfayı `Ctrl + F5` ile yenileyin.
