# Tiny Kingdom Idle

Oynanabilir HTML/CSS/JavaScript idle oyun prototipi.

## Özellikler

- Dokunarak odun toplama
- Otomatik kaynak üretimi
- Oduncu, madenci, çiftçi ve tüccar
- Ev, testerehane, maden, çiftlik, pazar ve kale
- Yükseltmeler
- 12 saate kadar offline kazanç
- Rastgele krallık olayları
- Prestij ve taç sistemi
- Otomatik kayıt
- PWA ve çevrimdışı kullanım

## Çalıştırma

En kolay yöntem:

1. Tüm dosyaları GitHub reposuna yükle.
2. GitHub Pages'i etkinleştir.
3. Verilen adresi telefondan aç.
4. Ana ekrana ekle.

Bilgisayarda doğrudan denemek için klasörü bir yerel sunucu ile aç:

```bash
python -m http.server 8000
```

Ardından tarayıcıda `http://localhost:8000` adresine git.
