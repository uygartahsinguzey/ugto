# Berna V15.1 — Modern Visual Update

GitHub Pages üzerinde çalışan, yalnızca HTML/CSS/JavaScript kullanan cozy üretkenlik oyunu.

## Özellikler

- SPA sayfa geçişleri
- Yuvarlak ilerleme halkalı Pomodoro ve molalar
- Prosedürel ortam sesleri
- Ajanda ve ders sistemi
- Günlük görevler, coin, XP, seviye ve seri
- Özgün neo-cozy Miki tasarımı ve yeni mikro animasyonlar
- Miki ihtiyaçları ve kostüm sistemi
- 2026 estetiğine uyarlanmış yaşayan oda, mağaza ve envanter
- Yerel arkadaş kodu sistemi ve oda ziyareti simülasyonu
- Haftalık istatistikler
- Tema, isim, süre, veri dışa/içe aktarma
- PWA ve çevrimdışı kullanım

## GitHub Pages

1. ZIP dosyasını açın.
2. İçindeki dosyaları deponuzun kök dizinine yükleyin.
3. GitHub → Settings → Pages bölümünde `Deploy from a branch`, `main`, `/(root)` seçin.
4. İlk yayın birkaç dakika sürebilir.

## Yerel test

Service Worker için bir yerel sunucu kullanın:

```bash
python -m http.server 8000
```

Ardından `http://localhost:8000` adresini açın.
